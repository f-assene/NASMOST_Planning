# Supports de cours

```
supports/<DÉPARTEMENT>/<cours>/<fichier>
supports/NMSI/NSI-3231/Chapitre 1.pdf
supports/STMO/Chimie pour ingénieurs/TD/Série 1.docx
```

- `<cours>` = le **code de l'EC** (`NSI-3231`) ou l'**intitulé du cours** tel qu'il figure dans
  l'emploi du temps. La casse, les accents, les espaces et la ponctuation ne comptent pas.
- Dans l'application, le cours affiche « 2 supports de cours » ; un appui sur le cours donne la
  liste et ouvre le fichier. Des sous-dossiers (`TD/`, `TP/`) sont possibles.
- Tous les formats sont acceptés (PDF conseillé). Éviter les fichiers de plus de 50 Mo.
- ⚠️ Ce dépôt est **public** : tout fichier déposé ici est lisible par tout le monde.
