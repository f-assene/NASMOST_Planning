# Supports de cours — GEM (Génie Énergétique Marine)

Un dossier par cours, nommé d'après le **code de l'EC** ou l'**intitulé du cours** tel qu'il figure
dans l'emploi du temps (casse, accents, espaces et ponctuation ignorés) :

```
supports/GEM/<code de l'EC>/Chapitre 1.pdf
supports/GEM/<Intitulé du cours>/TD/Série 1.docx
```

Dans l'onglet **GEM** de l'application, le cours affiche alors « n supports de cours » ; un
appui sur le cours en donne la liste et ouvre le fichier. « Mon parcours → Mes cours » les
montre aussi.

- Tous les formats sont acceptés (PDF conseillé). Éviter les fichiers de plus de 50 Mo.
- ⚠️ Ce dépôt est **public** : tout fichier déposé ici est lisible par tout le monde.
- Ce fichier README.md n'est pas affiché dans l'application. Voir aussi [`supports/README.md`](../README.md).
