# Accueil des nouveaux étudiants

Pages affichées dans l'application, menu ⋮ → **Accueil des nouveaux étudiants** : fonctionnement
de l'école, filières, contacts utiles, démarches administratives, informations importantes.

Un contenu = un ou deux fichiers **de même nom** :

```
01_Bienvenue.pdf     pièce jointe : image (.png .jpg .webp), .pdf, .docx ou .xlsx
01_Bienvenue.txt     description : 1re ligne = titre, puis le texte
```

Un `.txt` seul suffit pour un contenu texte. Lignes facultatives du `.txt` :
`Départements: NMSI, GCO` (ou `TOUS`) et `Expire: AAAA-MM-JJ`.
Les adresses web, e-mails et numéros de téléphone écrits dans le texte sont cliquables.

Les pages sont classées **par nom de fichier** : commencer par un numéro (`01_`, `02_`, ...).
Ce fichier README.md n'est pas affiché dans l'application.
