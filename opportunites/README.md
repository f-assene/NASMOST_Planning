# Opportunités

Stages, emplois, formations, bourses, certifications et appels à candidatures affichés dans
l'application, menu ⋮ → **Opportunités**.

Un contenu = un ou deux fichiers **de même nom** :

```
2026-10-20_Bourse_exemple.pdf     pièce jointe : image (.png .jpg .webp), .pdf, .docx ou .xlsx
2026-10-20_Bourse_exemple.txt     description : 1re ligne = titre, puis le texte
```

Un `.txt` seul suffit pour un contenu texte. Lignes facultatives du `.txt` :
`Départements: NMSI, GCO` (ou `TOUS`) et `Expire: AAAA-MM-JJ`.
Les adresses web, e-mails et numéros de téléphone écrits dans le texte sont cliquables.

Commencer le nom par la date `AAAA-MM-JJ_` (les plus récentes en haut) et indiquer la date limite
avec `Expire:` : l'opportunité disparaît d'elle-même ensuite.
Ce fichier README.md n'est pas affiché dans l'application.
