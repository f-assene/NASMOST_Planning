# Campus et communauté

Activités des associations (AIPEM, GIMA, AE...), événements, conférences et annonces étudiantes
affichés dans l'application, menu ⋮ → **Campus et communauté**.

Un contenu = un ou deux fichiers **de même nom** :

```
2026-10-25_Conference_exemple.pdf     pièce jointe : image (.png .jpg .webp), .pdf, .docx ou .xlsx
2026-10-25_Conference_exemple.txt     description : 1re ligne = titre, puis le texte
```

Un `.txt` seul suffit pour un contenu texte. Lignes facultatives du `.txt` :
`Départements: NMSI, GCO` (ou `TOUS`) et `Expire: AAAA-MM-JJ`.
Les adresses web, e-mails et numéros de téléphone écrits dans le texte sont cliquables.

Commencer le nom par la date `AAAA-MM-JJ_` (les plus récents en haut).
Ce fichier README.md n'est pas affiché dans l'application.
